## 규칙

1. **판을 덮어쓰지 않는다.** 코드는 같은 이름의 판이 있으면 멈춘다. 옛 판은 지우지 않는다.
2. **정본 표의 열을 고치지 않는다.** 관리 필드는 `obl_id`·`law_id` 같은 정본 키로 붙는 **별도 표**에 둔다 → 정본이 바뀌어도 조인만 다시 하면 된다.
3. **입력은 발행 판만** — 파일 수정시각이나 파일명으로 「최신」을 고르지 않는다(E66).
4. 모든 판에 `_MANIFEST.csv`(행수·sha1). `python _build\build_demo_db.py check` 로 바뀐 파일이 없는지 확인한다.
5. 검수 전 값은 `review_status = pending` 으로 남긴다. 화면에 그대로 노출한다(「법적 확정」 표시 금지).
