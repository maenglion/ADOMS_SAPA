# ops_v0.3_20260921 — 데모 2차 운영 데이터 (판)

생성 2026-09-21 · 생성기 `_build\build_ops_v03_seed.py` · TG99 정리 `_build\fix_tg99_v03.py`

## 이 판이 왜 있나

v0.1·v0.2 를 실측해 보니 **빈 표**가 있었다(evidence·inspection·action·notification 이 0행).
이행완료 과제가 1,018건인데 증빙이 한 건도 없으면 화면이 비어 보이고, 시연에서 「완료라는 근거가 뭐냐」에 답할 수 없다.
또 사용자 지적(09-21)으로 ① 기간초과 비중을 24.7% → 5.7% 로 낮추고 ② 담당자를 사람 이름으로 바꾸고
③ 관리대상 미분류(TG99) 382건을 잠정 분류했다.

## 규칙

* **앞 판을 덮어쓰지 않는다.** 앱은 표마다 ops_v0.3 → v0.2 → v0.1 순으로 찾는다(새 판 우선).
* 지어낸 값은 전부 `note` 에 「예시 데이터(시연용)」로 표시한다.
* **실존 인물 이름은 쓰지 않는다** — 이 시스템의 점검·결재 기록은 지어낸 것이라 실명에 붙이면 허위 기록이 된다.
  부서 이름만 실제 조직 이름을 쓴다. 담당자는 가상 인물이고 `staff.note` 에 그렇게 적었다.
* 난수 씨앗이 고정돼 있어 다시 돌려도 같은 값이 나온다.
